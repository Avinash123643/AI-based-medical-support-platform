# Workflow

1. Enter synthetic medical-related computational tasks.
2. Assign arrival time, burst time, and priority.
3. Select the highest-priority task among tasks that have arrived.
4. Simulate non-preemptive execution and calculate start/completion times.
5. Calculate waiting, turnaround, and response times.
6. Visualize the result and compare it with FCFS.
7. Compare illustrative resource requirements with a configurable resource pool.

This is an educational simulation, not a clinical decision-making system.
